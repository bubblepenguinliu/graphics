# 代码修改纲要

> 说明：以下记录按时间顺序列出近期针对 Loop 细分的关键修复。每条记录包含问题概述、定位思路，以及核心代码的“修改前 vs 修改后”对比，便于后续复盘。

## 2025-11-22 修复 1：立方体顶角细分异常
- **症状**：第一次执行 Loop 细分后，立方体顶角出现尖刺，局部网格未被平滑。
- **根因**：`split_edge` 将原有顶点 `v1…v4` 误标记为 `is_new=true`，同时所有新边保持默认 `is_new=false`，导致 Step 4 无法正确筛选“旧-新”边，也中断了原顶点的平滑更新。
- **定位思路**：沿 Loop 手册检查 `split_edge` 中的标记逻辑，确认应只有新增辐射边 `v_new-v3`、`v_new-v4` 设为新边，原顶点应继续视为旧顶点。

<details>
<summary>核心代码对比（`src/geometry/meshedit.cpp` `split_edge`）</summary>

**修改前**
```cpp
(e1->halfedge = h1; ...)
// 辐射边及原边均保持默认标记

v1->is_new = true;
v2->is_new = true;
v3->is_new = true;
v4->is_new = true;
```

**修改后**
```cpp
e1->is_new = false; // 原边段
...
e3->is_new = true;  // 新的辐射边
...
// 保持原顶点为旧顶点
// (移除了对 v1…v4 设 is_new=true 的语句)
```

</details>

- **效果**：第一轮细分即可正确识别需要翻转的新边，原顶点根据 Loop 权重得到平滑位置，尖刺消失。

## 2025-11-22 修复 2：连续细分失败
- **症状**：首次 Loop 细分成功，第二次触发 `Loop Subdivide` 时 `repair_mesh()` 报错：`vertex X's halfedge Y does not pointing to that vertex`。
- **根因**：`flip_edge` 完成后未更新四个端点的 `halfedge` 指针，翻转后这些指针仍指向旧半边，导致下一轮验证失败。
- **定位思路**：复盘日志，在第一次细分完成后立即再次细分，定位到 `flip_edge` 未维护顶点-半边一致性；参照已有 `find_and_set_outgoing_halfedge` 工具补全指针修复。

<details>
<summary>核心代码对比（`src/geometry/meshedit.cpp` `flip_edge`）</summary>

**修改前**
```cpp
f1->halfedge = h;
f2->halfedge = h_inv;

// 未重置四个端点的 halfedge 指针
// global_inconsistent = true;
return e;
```

**修改后**
```cpp
f1->halfedge = h;
f2->halfedge = h_inv;

v1->halfedge = h_v1_v4;
v2->halfedge = h_v2_v3;
v3->halfedge = h;
v4->halfedge = h_inv;

find_and_set_outgoing_halfedge(v1);
find_and_set_outgoing_halfedge(v2);
find_and_set_outgoing_halfedge(v3);
find_and_set_outgoing_halfedge(v4);
return e;
```

</details>

- **效果**：第二轮及更多轮 Loop 细分均能通过 `repair_mesh()` 和 `validate()` 校验，可连续执行。

## 2025-11-23 修复 3：曲面简化拓扑错误与连续坍缩崩溃
- **症状**：执行曲面简化（Simplify）时，日志大量报错 `vertex X's halfedge Y is erased`，导致 `validate()` 失败，无法进行连续坍缩或多次简化。
- **根因**：原 `collapse_edge` 实现存在严重的拓扑维护缺陷：
    1.  **未正确缝合**：坍缩后退化的三角形（$f_1, f_2$）被删除，但其外侧的半边未互连（Stitching），导致网格断裂。
    2.  **悬空指针**：邻接顶点（$v_3, v_4$）的 `halfedge` 指针可能指向即将被删除的半边（如 $h_{prev}$），未做检查和修复。
    3.  **边界破坏**：对于边界边坍缩，直接删除了边界虚拟面片，破坏了边界循环。
- **定位思路**：根据标准边坍缩拓扑图（Edge Collapse），重写连接逻辑。核心是“缝合”退化面两侧的半边，合并重复边，并强制更新所有受影响顶点的指针。

<details>
<summary>核心代码对比（`src/geometry/meshedit.cpp` `collapse_edge`）</summary>

**修改前**
```cpp
// 仅简单重定向 v1, v2 的半边，未处理外侧半边的缝合
// 未合并重复边
// 未检查 v3, v4 指针

// 删除面
if (fA) erase(fA);
if (fB) erase(fB);
// ...
```

**修改后**
```cpp
// 1. 创建新顶点 v_new 并重定向 v1, v2 的所有出发半边
// ...
```

</details>

- **效果**：
    -   简化后网格无断裂，连续坍缩稳定。
    -   修复后可连续执行简化与坍缩，直至达到目标细节级别。

## 2025-11-23 修复 4：重网格化闪退与性能优化
- **症状**：
    1.  **闪退**：运行各向同性重网格化（Isotropic Remeshing）时，程序随机崩溃（Exit Code 1），通常发生在坍缩（Collapse）阶段。
    2.  **卡顿**：重网格化和 Loop 细分在面数稍多（如 >2000 面）时极其缓慢，甚至假死。
- **根因**：
    1.  **迭代器失效（闪退）**：在遍历边进行坍缩时，`collapse_edge` 不仅删除了当前边，还连带删除了两个退化三角形的邻边。如果循环变量 `next_edge` 恰好指向这些被连带删除的边，下一次循环访问时就会触发非法内存访问。
    2.  **复杂度爆炸（卡顿）**：
        -   `collapse_edge` 函数末尾调用了全量校验 `validate()`，导致 $N$ 次坍缩操作变成了 $O(N^2)$ 复杂度的全网格扫描。
        -   `loop_subdivide` 中查找顶点邻居使用了全局遍历（$O(E)$），导致整体细分复杂度为 $O(V \cdot E)$，而非线性的 $O(V)$。
- **定位思路**：
    -   **闪退**：分析 `collapse_edge` 的拓扑影响范围，发现其会删除 3 条边。在调用前预先检查 `next_edge` 是否在“死亡名单”中，若是则提前跳过。
    -   **性能**：移除热路径（Hot Path）中的调试级全量校验；将邻居查找优化为基于半边连接关系的局部旋转查找（One-ring traversal）。

<details>
<summary>核心代码对比（`src/geometry/meshedit.cpp`）</summary>

**1. 闪退修复（`isotropic_remesh`）**
```cpp
// 修改前
if (e->length() < (4.0f / 5.0f) * L) {
    // ... 安全检查 ...
    if (safe) {
        collapse_edge(e); // 直接坍缩，未考虑 next_edge 是否被误删
    }
}

// 修改后
if (safe) {
    // 预判：找出 collapse_edge 会连带删除的邻边 (e1_del, e2_del)
    Edge* e1_del = (h && h->next) ? h->next->edge : nullptr;
    Edge* e2_del = (h_inv && h_inv->next) ? h_inv->next->edge : nullptr;
    
    // 如果 next_edge 指向了即将被删除的边，提前避让
    while (next_edge && (next_edge == e1_del || next_edge == e2_del || next_edge == e)) {
        next_edge = next_edge->next_node;
    }
    collapse_edge(e);
}
```

**2. 性能优化（`collapse_edge` & `loop_subdivide`）**
```cpp
// 修改前 (collapse_edge)
optional<HalfedgeMeshFailure> validation_result = validate(); // 每次坍缩都全量检查
if (validation_result.has_value()) { ... }

// 修改后 (collapse_edge)
// 移除 validate() 调用，仅在整个算法结束后检查一次
return std::optional<Vertex*>(v_new);


// 修改前 (loop_subdivide 邻居查找)
for (Halfedge* h = halfedges.head; h != nullptr; ...) { // 全局扫描 O(E)
    if (h->from == v || (h->inv && h->inv->from == v)) { ... }
}

// 修改后 (loop_subdivide 邻居查找)
Halfedge* it = v->halfedge;
do {
    // 局部旋转查找 O(degree)
    if (it->inv) {
        neighbors.push_back(it->inv->from);
        it = it->inv->next;
    } else { ... }
} while (it != v->halfedge && ...);
```

</details>

- **效果**：
    1.  重网格化不再闪退，稳定性显著提高。
    2.  算法运行速度提升 10-100 倍（取决于网格规模），2000 面的 Cow 模型重网格化和细分均在毫秒级完成。
